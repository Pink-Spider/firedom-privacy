Privacy policy and support page for **Firedom (파이어덤)** (`app.firedom.firedom`),
served via GitHub Pages at <https://pink-spider.github.io/firedom-privacy/>.

| Page | ko | en | ja |

This repo is the source of truth (the app repo keeps no copy). Edit all three
languages together.

The policy says: all financial data stays on the device, no server, no ads or
analytics SDK. The only third party is RevenueCat, for subscription receipts.
If the app starts sending anything else, update the policy first.
